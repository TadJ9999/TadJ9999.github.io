Connect GitHub

Edits are saved as commits to the private portfolio-src repo, then published automatically in about a minute.

  1. Open GitHub › New fine-grained token.
  2. Repository access: Only select repositories › portfolio-src.
  3. Permissions: Contents Read and write, Actions Read-only (for publish status).
  4. Set an expiry, generate, and paste it below.

The token stays in this browser and is only sent to api.github.com.
